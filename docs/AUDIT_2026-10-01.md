# HazardPulse audit, 2026-10-01/02: findings, fixes, measured impact

Branch `fix/hazardpulse-truth-20261001` (from `main` aedf08cd1). Every number below was
measured on this branch unless marked otherwise. Evidence classes: **MEASURED** (run and
recorded here), **DERIVED** (from code or the repo's own documents), **HYPOTHESIS**.

## 1. Headline

The tornado storm-object model's published AUC (0.894) rested on labels with the wrong
clock and on HRRR features read from the wrong place. Corrected and retrained, it measures
**AUC 0.940 [0.930, 0.947]** on every 2024 storm object (1,004,531; base rate 0.32%;
interval resampled by day) and is **calibrated** (Brier skill +0.056). What served live
until now scored **BSS −8.48** against climatology over 1,737 matured forecasts. The
hurricane scorer had not produced a forecast since 2026-05-26; it runs again, with a
retrained model (AUC 0.847, BSS +0.145) replacing one that scored worse than climatology.

## 2. Tornado: the measurement ladder

Rebuilt 2021–2024 cache (762 ProbSevere days; 6,092 of 6,096 3-hourly HRRR analyses, the 4
missing are archive gaps). Train 2021–2022, validation 2023, test 2024.

| Arm | What changes | Train / test positives | Full-model test AUC |
|---|---|---|---|
| A | old code verbatim (stamp-format shim only) | 638 / 508 | 0.875 [0.860, 0.890] ¹ |
| B | A + label clock fix only | 4,781 / 3,335 | 0.911 [0.906, 0.917] ¹ |
| C | every fix (served) | 4,635 / 3,235 | **0.940 [0.930, 0.947]** |
| C18 | C, but every storm reads 18Z (the leak) | 4,622 / 3,235 | 0.937 [0.928, 0.945] |
| C0 | C, torsion forced to zero | 4,635 / 3,235 | 0.940 [0.931, 0.948] |

¹ old evaluation: 5:1-downsampled test, sample-level bootstrap (intervals too narrow).

- **Label clock (finding #2): MEASURED.** The old labels marked about 86% of storms that
  were followed by a tornado as tornado-free (638 vs 4,635 train positives on the same
  1.74M storm objects). The clock fix alone moved the full model 0.875 → 0.911.
- **Coherence block:** published lift +0.015; A +0.026; with correct labels only (B)
  **+0.0003 [−0.0007, +0.0014], p = 0.28**; with every fix (C) **+0.0020 [+0.0001,
  +0.0038], p = 0.021** (day-clustered). Small and marginal. HRRR block in C: +0.0062
  [+0.0034, +0.0092].
- **18Z leak:** time-matched analyses score slightly higher than the leaked fixed 18Z
  (0.940 vs 0.937), and the HRRR block's lift doubles (+0.006 vs +0.003): the honest
  atmosphere is also the more informative one.
- **Torsion (finding #1):** importance 0.0 in A and B; 0.011 (+0.018 for torsion × SRH) in
  C -- a real field the trees now use. But forcing it to zero (C0) leaves the full model
  unchanged (0.9400 vs 0.9395; coherence lift without torsion +0.0024 [+0.0004,
  +0.0045]). **Torsion is no longer inert, and it carries no predictive information
  beyond the other 40 features.** The coherence block's small lift comes from τ and
  alignment.
- **Calibration of the served model:** bulk forecasts 0.24% verify at 0.27% (1.0M); the
  two top bins are under-confident (13–21% forecasts verify at 22–43%, n = 2,352).
- **NPE analytic blend:** fed physical features for the first time it scores AUC 0.876 and
  BSS −5.7. It is not used by tier 1; the same hand-tuned formula is the live tier-2
  fallback and is not calibrated to any population (HYPOTHESIS for its live effect).
- **Against NOAA's own ProbTor** (same 1,004,531 storms, same labels; ProbTor had to be
  re-fetched -- the parser had stored 0 for every storm, see T21): served model AUC
  **0.940** vs ProbTor **0.842 [0.816, 0.863]**, paired day-clustered delta **+0.097
  [+0.082, +0.116]**. Raw ProbTor BSS −0.059; recalibrated *in-sample* (a hindsight upper
  bound) +0.056, equal to the model's +0.056. So the edge is in RANKING, plus calibration
  that holds without hindsight. 27% of tornadic storm-observations (858 of 3,235) are
  storms ProbTor rates < 1%; among those the model scores 0.873. Caveat (HYPOTHESIS): our
  label is a 40 km neighbourhood ("a tornado within 40 km in 60 min"), ProbTor's is the
  storm itself; many of those 858 are likely neighbours of the tornadic storm, so part of
  the edge may be the easier task. Test: a per-storm label (report inside the polygon).
- **Live replay**, held-out evening 2024-04-27 22:30Z: 87 storms, 4 tornadic within 60
  min; 3 of the 4 are the model's top 4 (20.7%, 14.1%, 14.0%).

## 4. Not done / decisions

- **PENDING, measured, fix written:** the tornado model identity hashes raw payload bytes, so
  one model has two names -- `tornado_gbt_v2-77c3b0078761` on a Windows (CRLF) checkout, which
  is what the committed registry shows, and `…48637c637e01` in Linux CI, which is what live
  forecasts carry. The fix (normalise CRLF before hashing, as `hurricane.ri_model.sha256_file`
  already does, plus a test that fails without it) is held as
  `PENDING_tornado_identity_crlf.patch` and applied at the v3 ship step: `definitive_model.py`
  is a fingerprinted producer of the v3 feature store, and changing it now would rebuild
  every stored day for a change that touches no feature. The registry is regenerated then.

- **Earthquake models** were trained on the truncated catalog (E1); retraining needs the
  derived feature caches rebuilt first (`HAZARDPULSE_*_REBUILD`). The served earthquake
  probabilities are unchanged by this branch except the serving window (E4).
- **Trust-layer calibrators** for tornado (v2) and hurricane (v8.2) refit only after new
  forecasts mature; until then the models' own held-out calibrations are served, without
  Venn-Abers bands or signed receipts.
- **HRRR-env research tier** does not beat STP alone on the honest benchmark; the shipped
  v1 forest is unserved and refused by its scorer (trained on g1 grids).
- **Earthquake retrain runner**: register one or keep retraining manual.
- **Top-bin under-confidence** of the tornado model: a monotone (isotonic / Venn-Abers)
  calibrator on the 2023 population would address it; not done.
- The day-level tornado models in `README.md` (formation 0.644, severity) were not
  re-examined; they key SPC reports by date and may share the CST/UTC date issue
  (HYPOTHESIS).

```
# copied in (it only shims the stamp format and, for B, the label clock)

python scripts/audit_20261001/ladder_legacy.py B out/B

python scripts/calibrate_torsion_threshold.py 0.90

```
